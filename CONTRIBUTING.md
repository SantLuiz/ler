# Contributing

Use Bun 1.4.4. Install with `bun install --frozen-lockfile`, then run `bun run typecheck` and `bun test`. Keep parsing, layout and persistence independent from UI components. Add behavior tests for parser or state fixes, with small self-authored fixtures. Do not commit personal EPUBs, library state or screenshots containing copyrighted book passages.

For rendering changes record Windows Terminal version, window dimensions and image protocol. Exercise scrolling, resize, tab switching and exit cleanup. Describe user-visible behavior and validation in pull requests. Add English and Portuguese interface text together.
